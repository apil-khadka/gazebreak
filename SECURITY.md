# Security Policy

## Supported versions

Only the latest release on the [Releases page](https://github.com/apil-khadka/gazebreak/releases) is supported with security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/apil-khadka/gazebreak/security/advisories/new). Do not open a public issue or include secrets, tokens, or personal information in a public report.

Include the affected version, a concise description, reproduction steps, and any suggested mitigation. Reports will be reviewed before public disclosure.
